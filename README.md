# Network Attack Detection Using Machine Learning in R

This project applies machine learning techniques to classify network traffic as Normal or Attack using network flow features.

## Project Overview

The project focuses on analysing cybersecurity network traffic data and building machine learning models for attack detection.

## My Contribution

This was a group academic project. My main contribution focused on:

- Data exploration for `sttl`, `ct_srv_dst`, and `sbytes`
- Statistical analysis and visualisation
- Logistic Regression modelling
- Random Forest modelling
- Model evaluation using confusion matrix, accuracy, sensitivity, specificity, ROC curve, and AUC

## Tools and Libraries

- R
- dplyr
- ggplot2
- randomForest
- pROC
- caTools
- plotly
- VIM

## Machine Learning Models

- Logistic Regression
- Random Forest

## Key Outcome

The Random Forest model showed strong performance for detecting attack traffic, suggesting that non-linear machine learning models are useful for identifying complex cybersecurity patterns.
